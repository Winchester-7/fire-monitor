# Golden Dragon Fire Monitor

Веб-приложение для iPhone: уведомления о срабатывании датчиков FireSec в Golden Dragon Hotel.
Данные объекта (site.enc) зашифрованы кодом подключения.

## v3

- Полноэкранный экран тревоги: часы, таймер с момента срабатывания, кнопка «Принял», план с волной от датчика и зелёным путём к выходу.
- Повтор тревоги следующему по списку, если никто не принял (нужен агент 1.1).
- Время «Принял», «Звук отключён» и «Сброс» у каждой тревоги.
- Живой статус и точное время последней связи с агентом.
- Журнал с фильтром по этажам и тепловая карта ложных срабатываний.
- Неисправности жёлтым и без сирены. Своя сирена в приложении, значок на иконке.
- Выходы на планах: `exits.js` (первая разметка, уточняется в приложении: «Этажи 3D» → 🚪).
